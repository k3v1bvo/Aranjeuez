# Paseo Aranjuez — Ecosistema Digital

Proyecto desarrollado para la Hackathon by Paseo Aranjuez.

## Ecosistema
- **PaseoYa** — Marketplace + pedidos con retiro presencial
- **Paseo Points** — Sistema de fidelizacion y recompensas
- **Jarvis Paseo** — Asistente inteligente con IA (Gemini)

## Stack
- Next.js 16 + TypeScript
- Supabase (Auth + DB + Realtime)
- Tailwind CSS v4
- Google Gemini AI (Jarvis)

## Setup

```bash
npm install
cp .env.example .env.local
# Completar variables de entorno
npm run dev
```

## Variables de entorno requeridas
Ver `.env.example`
